# កត់ចំណងដៃ Pro (Katchongdai) 🇰🇭

**ប្រព័ន្ធគ្រប់គ្រង និងកត់ត្រាចំណងដៃឌីជីថលគ្រប់កម្មវិធី ពេញលេញកម្រិតខ្ពស់**  
*Full-Stack Cambodian Ceremony & Gift Money (Chongdai) Management Platform*

---

## ✨ មុខងារសំខាន់ៗទាំង ១០ ផ្នែក (Complete Feature Suite)

1. **ផ្ទាំងគ្រប់គ្រងរួម (Executive Multi-Ceremony Dashboard)**
   - បង្ហាញទិន្នន័យសរុបគ្រប់កម្មវិធីទាំងអស់ក្នុងប្រព័ន្ធ (ប្រាក់ដុល្លារ `$` ប្រាក់រៀល `៛` សមមូលសរុប ចំណាយសរុប សមតុល្យចំណេញ/ខាត និងចំណងដៃទៅវិញទៅមក)។
2. **គាំទ្រគ្រប់ប្រភេទកម្មវិធី (All Cambodian Ceremony Types)**
   - 💍 ពិធីមង្គលការ (អាពាហ៍ពិពាហ៍)
   - 🌸 ពិធីភ្ជាប់ពាក្យ
   - 🏡 ពិធីឡើងគេហដ្ឋានថ្មី (ឡើងផ្ទះ)
   - 🪷 ពិធីបុណ្យកឋិនទាន / បុណ្យទាន / បុណ្យផ្កាប្រាក់
   - 🕯️ ពិធីបុណ្យសព / បុណ្យ ៧ថ្ងៃ - ១០០ថ្ងៃ
   - 🎂 ពិធីបង្កក់កូន / ខួបកំណើត
   - 🎊 ពិធីសម្ពោធហាង / ក្រុមហ៊ុន
   - ✨ កម្មវិធីផ្សេងៗតាមតម្រូវការ
3. **តុទទួលភ្ញៀវកត់ត្រារហ័ស (Fast Reception Desk Mode)**
   - រចនាឡើងសម្រាប់អ្នកកត់ត្រានៅតុទទួលភ្ញៀវផ្ទាល់ ជាមួយប៊ូតុងគោរមងាររហ័ស (`លោក`, `លោកស្រី`, `ឧកញ៉ា`, `ឯកឧត្តម`...), ការបំពេញឈ្មោះស្វ័យប្រវត្តិ (Smart Autocomplete) ភ្ជាប់ជាមួយបញ្ជីធៀបអញ្ជើញ និងប្រវត្តិចំណងដៃពីមុន។
   - គាំទ្រការបញ្ចូល **ប្រាក់ដុល្លារ (`$`) និងប្រាក់រៀល (`៛`) ក្នុងពេលតែមួយ** រួមទាំងវត្ថុអនុស្សាវរីយ៍/មាសប្រាក់។
4. **សៀវភៅបញ្ជីចំណងដៃផ្លូវការ & បោះពុម្ព PDF / Excel CSV**
   - ស្វែងរក និងច្រោះទិន្នន័យតាមវិធីបង់ប្រាក់ (`សាច់ប្រាក់`, `ABA KHQR`, `ACLEDA`, `Wing`), ខាងកូនប្រុស/កូនស្រី, ក្រុមភ្ញៀវ។
   - នាំចេញជាឯកសារ **Excel CSV (UTF-8 BOM)** មិនបែកអក្សរខ្មែរ នាំចូល CSV និងបោះពុម្ព **សៀវភៅកត់ត្រាចំណងដៃផ្លូវការ (A4 Print / PDF)** ព្រមទាំង **បង្កាន់ដៃថ្លែងអំណរគុណមាន QR Code**។
5. **បញ្ជីភ្ញៀវអញ្ជើញ & ផែនទីរៀបចំតុភ្ញៀវ (RSVP & Visual Banquet Table Planner)**
   - តាមដានការជូនធៀប ចំនួនកៅអីបម្រុងតាមតុ (`VIP-1`, `T-01`...) និងចុច ១ដងដើម្បីកត់ចំណងដៃពេលភ្ញៀវមកដល់។
6. **ធៀបអញ្ជើញឌីជីថល & ចំណងដៃអនឡាញ (Digital E-Invitation & KHQR Portal)**
   - បង្កើតកាតអញ្ជើញឌីជីថលភ្ជាប់ QR Code (KHQR) និងទម្រង់ផ្ញើចំណងដៃ + ពាក្យជូនពរអនឡាញសម្រាប់ភ្ញៀវនៅឆ្ងាយ (មានមុខងាររង់ចាំម្ចាស់កម្មវិធីផ្ទៀងផ្ទាត់អនុម័ត)។
7. **គ្រប់គ្រងចំណាយ & គណនេយ្យកម្មវិធី (Expenses & Net Surplus Accounting)**
   - កត់ត្រាថ្លៃចុងភៅ សម្អាងការ រោងការ ភេសជ្ជៈ ថតរូប ប្រាក់កក់មុន ប្រាក់នៅខ្វះ និងគណនាចំណូល-ចំណាយសុទ្ធ។
8. **រាប់សាច់ប្រាក់ក្នុងហិប & ផ្ទៀងផ្ទាត់ (Cash Box Denomination Reconciliation)**
   - រាប់សន្លឹកប្រាក់តាមប្រភេទក្រដាសប្រាក់ `$100..$1` និង `100,000៛..100៛` ធៀបផ្ទាល់ជាមួយសាច់ប្រាក់ក្នុងសៀវភៅកត់ត្រា ដឹងភ្លាមថាត្រូវគ្នាគត់ លើស ឬខ្វះ។
9. **សៀវភៅចំណងដៃទៅវិញទៅមក (Reciprocity & Outgoing Chongdai Directory)**
   - កត់ត្រាចំណងដៃដែលយើងទៅចូលរួមកម្មវិធីគេ និងឆែកប្រវត្តិទៅវិញទៅមកគ្រប់ឆ្នាំ (*គាត់ធ្លាប់ចងដៃយើងប៉ុន្មាន vs យើងធ្លាប់ចងដៃគាត់ប៉ុន្មាន*) ព្រមទាំងផ្តល់យោបល់ចំនួនទឹកប្រាក់គួរចងតប។
10. **របាយការណ៍វិភាគ ស្ថិតិ កំណត់ហេតុសុវត្ថិភាព & Full JSON Backup/Restore**

## 🛠️ បច្ចេកវិទ្យាប្រើប្រាស់ (Tech Stack)

- **Frontend:** React 19, Vite 6, Tailwind CSS 4, Lucide Icons, Khmer Typography (`Kantumruy Pro`, `Battambang`, `Moul`)
- **Backend:** Node.js 22, Express 5 REST API, Real QR Code Generator (`qrcode`)
- **Database:** Built-in SQLite (`node:sqlite` WAL mode) persisted in `data/katchongdai.db`

---

## 🚀 របៀបដំណើរការ (Getting Started)

```bash
# ដំឡើងកញ្ចប់បណ្ណាល័យ
npm install

# ដំណើរការម៉ាស៊ីនមេសម្រាប់អភិវឌ្ឍន៍ (Express API + Vite HMR លើ Port 3000)
npm run dev

# ចងក្រងសម្រាប់ Production
npm run build
npm start
```
